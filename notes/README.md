# Notes for Phoebe Affirmations

Shared notes so Claude, ChatGPT, Phoebe and Lee can all work from the same brief without copying and pasting.

**This repository is public.** Only design and art notes belong here. Personal notes, chart readings and anything about clients go in a private repository.

- `design-brief.md`: the look and feel of the whole deck and website.
- `cards/`: one file per card pair, with its colours and the art brief for its card image.

How to use it: at the end of a session, ask Claude or ChatGPT to update these notes. The other AI can then read them and pick up where things left off.
